# 今天我来当大厨 · 微信小游戏原型

可爱卡通风的「抓大鹅」式消除小游戏：锅里堆满食材，点食材放进 7 格托盘，3 个相同的消除；按顾客订单做菜通关。

## 运行
浏览器不能直接双击打开（需要通过服务器加载模块和图片）。在本文件夹里执行：

    python3 -m http.server 8765

然后浏览器打开 http://localhost:8765 （建议用手机竖屏或浏览器开发者工具的手机模式）。手机测试：电脑和手机连同一个 WiFi，打开 http://电脑IP:8765 。
不需要联网：Three.js 和 cannon-es 都已放在 vendor/ 里。
加 `?autostart=1` 可以跳过标题画面，直接开始第 1 关。

## 玩法
- 点锅里的食材放进底部 7 格托盘，同类凑 3 个消除；托盘满 7 个就失败。
- **做菜订单（主线）**：顶部有 1～3 张顾客订单（左边是顾客头像，右边是菜品），例如"番茄炒蛋"需要消除番茄、鸡蛋各一组。消除的食材自动算进订单，做完一单得金币，然后出现新订单。完成本关要求的订单数就过关。锅会自动补订单需要的食材，不会卡死。
- **小厨师**：点小厨师，会把托盘最后一个食材放到他手里的盘子上（相当于临时第 8 格），再点一下放回托盘。他有待机、开心、担心、难过、端盘、点赞几种表情。
- **辣椒**（第 2 关起）：消除 3 个辣椒会爆炸，把附近的食材炸开。
- **冰块**（第 3 关起）：被冰住的食材要先点 2 下把冰敲碎，才能拿。
- "摇一摇"（右下角蓝色按钮，角标是剩余次数）每关 2 次，把锅里的东西抛起来打乱。

## 画面实现
- 食材是 2D 贴图（THREE.Sprite，永远朝向镜头）放进 3D 物理世界（cannon-es，球形碰撞体），每个食材脚下有一个圆形软阴影。
- 锅（`art/ui/pot.png`）是放在画布后面的 DOM 图片，代码会按物理锅半径 `potRadius` 的屏幕投影自动缩放对齐，所以每关锅大小不同也不会错位；物理墙是看不见的。
- 托盘、订单卡、小厨师、弹窗都是 HTML + 图片，位置按图片比例写成百分比。

## 改配置（只改 `config.js`）
- `items`：食材的 id、中文名、图片路径 `image`；`special: 'chili'` 表示辣椒。换图只需替换 PNG（透明底，正方形）。
- `itemSize` / `spriteScale`：食材大小；`colliderScale`：碰撞球相对大小。
- `art`：背景、锅、托盘、订单卡、冰块、特效、小厨师各表情的图片路径；`customers`：顾客头像列表。
- `dishes`：菜品订单，包括名称、图标 `image`、需要的食材组数 `needs`、奖励金币 `coins`。
- `levels`：每关的订单池 `dishes`、要完成的订单数 `goal`、同时显示几张订单 `maxOrders`、干扰食材组数 `fillers`、锅里少于多少个就补货 `minPot`、辣椒组数 `chili`、被冰住的比例 `ice`、锅的大小 `potRadius`。
- `chili.radius / power`：辣椒爆炸的范围和力度；`ice.taps`：敲冰需要点几下。

## 调试
浏览器控制台里有 `__game`：`start(n)` 跳到第 n+1 关（同时关闭标题画面）；`orders()` 看订单进度；`helper()` 相当于点小厨师；`tray` 看托盘；`coins` 看金币；`pickId('tomato')` 点一个番茄；`clickableCount()` 当前能点到的食材数；`outsideRim()` 锅外的食材数（应为 0）。

## 文件结构
- index.html / game.js / config.js：页面、规则、配置
- art/ingredients/：15 种食材（192px）
- art/dishes/：9 个菜品图标（224px）
- art/chef/：小厨师 6 个表情（idle / happy / worried / sad / holding / cheer，256px）
- art/customers/：6 个顾客头像（cat / bunny / panda / duck / bear / fox，160px）
- art/ui/：背景、锅、托盘、订单卡、金币、按钮、冰块（完整 / 裂开）、胜负弹窗、Logo
- art/fx/：爆炸、消除、蒸汽
- vendor/：three.js r160、cannon-es 0.20
- ART_LIST.md：全部美术资源清单和出图提示词（已全部完成）

## 包体
整个文件夹压缩后约 0.9MB，满足微信小游戏主包 4MB 的限制。
